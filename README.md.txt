# 🛒 E-Commerce Backend Project (Java + MySQL)

This project is the backend foundation of an E-Commerce system developed using **Core Java (JDBC)** and **MySQL**.

It demonstrates database design, table relationships, and Java–Database connectivity.

---

## ✅ Features Implemented

* Database Designed (`ecommerce_db`)
* Tables Created:

  * User
  * Product
  * Orders
  * Cart
* Foreign Key Relationships Implemented
* Java Connected to MySQL using JDBC
* Project Initialized for further development

---

## 🛠 Tech Stack

* Java (Core Java + JDBC)
* MySQL
* SQL
* Eclipse IDE
* Git & GitHub

---

## ⚙️ Database Setup Instructions

1️⃣ Open MySQL Workbench / Command Line
2️⃣ Run the SQL file:

```
database/ecommerce.sql
```

3️⃣ Database and tables will be created automatically.

---

## 🔌 Configure Database Connection

Update MySQL username & password in your Java connection file:

```java
String url = "jdbc:mysql://localhost:3306/ecommerce_db";
String username = "root";
String password = "your_password";
```

---

## 🚀 How to Run Project

1. Import project into Eclipse
2. Add MySQL Connector JAR
3. Configure DB credentials
4. Run the Java file
